# 节奏：日 / 周 / 月 / 季

## 1. 会话级（每次开工-收工）

**开工清单**
- [ ] `journal.py resume --root <root>`
- [ ] 向用户复述现状（阶段 / 卡点 / 下一步），确认方向
- [ ] 明确本次会话的"完成定义"

**收工清单（不可跳过）**
- [ ] 按 MUST-RECORD 触发器逐条落盘
- [ ] 有数字 → `metric` / `ledger`
- [ ] 阶段变了 → `stage`
- [ ] 更新 `NEXT-ACTIONS.md`
- [ ] `journal.py index` 与 `journal.py lint`
- [ ] 向用户汇报新增条目 ID

> 一天可以跑多个会话：全部追加进同一份 `journal/YYYY-MM-DD.md`，脚本按时间顺序自动排列。

## 2. 日

- 一天结束（或会话结束）时补记当天
- 判断今天是否"有值得记的"：只要发生了取舍、卡点、认知更新、数字变化，就有
- 纯执行日（比如连续调样式）可以只记一条 `T`：今天做了什么 + 有无阻塞
- 连续 7 天没有任何记录 → `lint` 会警告：项目还在跑吗？补记，或者体面地关掉它

## 3. 周（每周固定 15 分钟）

```bash
journal.py review --period weekly
```
生成的骨架里**自动事实**已经填好，你只需要写"分析"段。硬性要求：
- 本期最有价值的 3 条（写清为什么有价值）
- 卡点与解法（可复用吗？不可复用的解法不算资产）
- 认知更新（原想法 → 现在 → 依据）
- 数字解读：**解释涨跌原因，不要复述数字**
- 下期只做一件最重要的事（写进 `NEXT-ACTIONS.md`）
- 需要止损/放弃的东西（主动砍）

## 4. 月

- `journal.py review --period monthly`
- 检查三件事：变现假设**是否仍成立**、成本是否在累积而未产生收入、有没有掉进"自嗨"（做了很多但没人付钱）
- 对照 `CHARTER.md` 的成功线/止损线，记录当前距离有多远
- 阶段若推进，用 `stage --set` 并写清原因

## 5. 季 / 项目终止

- 触达止损线 → 立刻 `closeout --outcome failure`，不要拖（拖延是隐性成本）
- 达致成功线 → `closeout --outcome success`
- 转向 → `closeout --outcome pivot`，然后为新方向 `init` 一个新记录目录（保留旧的作为历史）
- 终局后：`publish` 生成资产包

## 6. 心跳（可选）

宿主支持定时任务时（DSH 的 `schedule_create`、系统 cron、CI），每天固定时间提醒"补记今日"。提醒文案示例：

> 补记 <项目> 今日过程：跑 `journal.py resume --root <root>`，把今天的取舍/卡点/数字写入日记，然后 `lint`。

心跳只是提醒，**真正的持续性来自 AGENTS.md 锚点 + 收工清单**。
