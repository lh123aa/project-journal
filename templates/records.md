# 档案模板（按类型复制）

> 用 `journal.py add --type <T> --title "..." --body-file <文件>` 时，脚本会把正文原样写入档案。
> 下面每个模板就是 `--body-file` 该写的内容。**注意：档案里不要再写一级标题**（脚本已用 --title 生成）。

---

## decision（决策）
```markdown
- 背景/触发：
- 选项：
  - A.
  - B.
- 决定：
- 理由：
- 代价与风险：
- 证据：（路径 / 链接 / 数据）
- 下一步：
```
命令：
```bash
journal.py add --type decision --title "放弃 WhatsApp 渠道" --body-file d.md --tags 渠道,获客
```

## problem（问题）
```markdown
- 症状：（可观察到的现象，含复现率与报错原文关键行）
- 影响：（阻断了什么、已阻塞多久、有没有金钱损失）
- 排除过程：（试过哪些假设，各自为何被否）
- 根因：（确认了吗？还是"疑似"？）
- 代价：（时间 / 金钱 / 机会）
- 关联：
```
解决后回填：
```bash
journal.py update --id PB-0003 --status solved --append-file solved.md
```

## solution（解法 / 打法）
```markdown
- 适用场景：
- 步骤：
  1.
  2.
- 关键要点/坑：
- 验证方式：（怎么知道有效）
- 可复用程度：（本项目专用 / 换项目也能用）
```

## experiment（实验）
```markdown
- 假设：
- 做法：
- 成功判据：（数字 + 时间窗，事前写死）
- 成本：
- 结果：
- 结论：（继续 / 放弃 / 改造）
```

## insight（认知更新）
```markdown
- 原来的想法：
- 现在的想法：
- 依据：（数据 / 观察 / 反例）
- 对我的影响：（接下来的动作要改什么）
```

## lesson（教训）
```markdown
- 一句话：（可脱离本项目独立成立）
- 代价：（时间 / 金钱 / 机会，要有数字）
- 适用边界：（什么情况下适用，什么情况下不适用）
- 复现信号：（出现什么迹象说明我正在重蹈覆辙）
```

## risk（风险）
```markdown
- 风险：
- 触发条件：
- 影响面：（会死还是会疼）
- 应对：（规避 / 缓解 / 接受）
- 当前状态：
```

## milestone（里程碑）
```markdown
- 事件：
- 日期：
- 意义：
- 当时的关键动作：
```

## 日记条目速记（不经档案时直接写进 daily）

```markdown
### HH:MM [T] 标题
- 做了什么：
- 结果：
- 阻塞：
```
